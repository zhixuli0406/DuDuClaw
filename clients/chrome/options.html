DuDuClaw 設定

一次性設定：gateway 來源白名單。瀏覽器擴充功能連線時會帶 chrome-extension://… 的 Origin，gateway 預設只信任 loopback 網頁來源。 請把下面這個擴充功能 id（純 id，不含 scheme）加進 gateway 的 config.toml → [gateway] allowed_origins（或環境變數 DUDUCLAW_ALLOWED_ORIGINS），並重載設定：

隱私聲明：本擴充功能只連線到你在上方設定的 gateway 位址， 不傳送任何資料到其他伺服器、不含遙測。登入換得的 token 存在瀏覽器的擴充功能儲存區。
