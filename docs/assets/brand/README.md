# DuDuClaw brand assets

The DuDuClaw C1 mark, icon, avatar and README banner used by the dashboard,
the desktop app, the OAuth pages and the READMEs.

| File | Use |
|------|-----|
| `duduclaw-mark.svg` | Two-colour mark (navy ink, amber tail). A byte-identical copy lives at `crates/duduclaw-cli/assets/duduclaw-mark.svg` for the OAuth pages; a test fails if the two drift apart. |
| `duduclaw-mark-mono.svg` | One-colour mark |
| `duduclaw-icon-1024.png` | App icon, 1024 × 1024 |
| `duduclaw-avatar-1024.png` | Square avatar for accounts and stores |
| `duduclaw-readme-banner.png` | README header banner |

Colour tokens and usage rules: `web/DESIGN.md`.
