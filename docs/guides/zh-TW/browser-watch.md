# 觀看員工的瀏覽器

啟動來源必須是當下已驗證的真人回合。背景工作即使帶著部屬身分，也不算真人啟動。系統會保留入場時的來源事實；回合結束後仍可據此判斷團隊觀看，但不會延長人在場或操作權限。

登入儀表板後，開啟 `/computer/<員工代號>`。這個頁面只提供瀏覽器操作入口，
不會增加員工設定、檔案、記憶或對話的讀取權限。

原本直接綁定的帳號沿用既有即時畫面與操作權限。經由部屬關係取得權限的主管，
只能看遮罩快照及結束該工作階段；不能取得原始串流、接手、交還、解除疑似注入
暫停，或清除登入狀態。

團隊觀看限企業版，與團隊對話查閱共用 `[people] manager_team_history` 設定。
只有符合資格的部屬在本次啟用期間啟動的工作階段才可觀看。多人共用同一位 AI
員工，不代表主管能看其他人的工作階段。每次請求都會重新確認權限；關閉設定、
停用主管帳號、移除部屬或降低部屬綁定權限後，都會拒絕團隊觀看。

頁面在前景時每兩秒更新，所有觀看者共用快取，最多每五秒擷取一次新畫面。
觀看不會排在員工操作前方，也不會喚醒已暫停的瀏覽器。舊快照會標示時間；
新請求被拒絕時，頁面會清掉原有畫面。即使快取原先沒有遮蔽，出現安全暫停後
也會整張遮蔽。

遮罩涵蓋密碼、付款欄位與敏感視窗，不會移除頁面上的所有姓名、電子郵件或其他
個資。觀看會留下紀錄，查閱稽核不保存圖片。紀錄只對應實際啟動該工作階段的
部屬，不會把共用同一員工的所有人都列進去。同一觀看者與工作階段的重複輪詢，
每分鐘合併一筆。觀看請求有每人上限，結束操作不受觀看額度限制。

結束確認會綁定當時顯示的工作階段。若原工作階段已結束並重新啟動，舊確認
不能結束新的工作階段。

macOS 本機瀏覽器是另一項功能，隱私範圍不同；團隊觀看不得提供它的網頁畫面。
受控 Docker 與儀表板測試，也不代表已完成各平台或真實服務商驗收。

## 從對話或工作紀錄開啟

容器瀏覽器在已驗證的對話中啟動時，WebChat 可顯示觀看按鈕。Telegram、LINE、
Discord 與 Slack 會沿原帳號及討論串通知；只有已對應儀表板使用者，且已設定
非本機的儀表板位址時才附連結（須由管理員確保可連線），否則只顯示文字。通知採盡力送達，不影響
瀏覽器是否已啟動。背景工作會把入口留在對應的工作或執行紀錄。

開啟連結後，照常登入並完成必要的第二階段驗證，儀表板會返回該瀏覽器。
連結最長有效 30 分鐘，只對應一個工作階段，不會增加權限。開啟及觀看時
都會重新確認權限；轉傳連結也不會讓別人取得觀看權。

透過連結觀看時，即使原本有直接綁定，也只顯示遮罩快照，以及對應該工作
階段的結束確認。連結過期或瀏覽器重新啟動後，舊畫面與按鈕會清除。若要
查看新的工作階段，請明確按下頁面的目前工作階段入口，再依原有權限操作。
觀看連結不能當作登入憑證。
