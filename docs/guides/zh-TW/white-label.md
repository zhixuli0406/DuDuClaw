# 總經銷的產品名稱與 Logo

v1.78.0 起，總經銷的客戶不限授權方案，都可以取得產品名稱與 Logo。gateway 會自動接收並驗證目前訂閱對應的品牌。開源版與未啟用授權的安裝沒有訂閱，使用原本的 DuDuClaw 品牌。

客戶不必安裝品牌檔案或修改設定。設定檔、HTTP 與 RPC 都沒有供客戶修改名稱與 Logo 的入口；舊的 `branding.json`、`branding.bundle.json` 會被忽略。需要變更或移除品牌時，請聯絡總經銷。

## 接收品牌更新

品牌文件必須驗簽通過、訂閱與目前授權完全一致，而且授權須通過期限與離線寬限檢查，品牌才會生效。沒有有效品牌時，gateway 使用 DuDuClaw；取件或文件驗證失敗不會擋住啟動。

更新失敗時，只要目前授權仍有效、訂閱仍一致，就保留已驗證的品牌。總經銷明確移除品牌、授權失效、訂閱變更，或快取文件驗證失敗時，品牌會停用。儀表板在登入工作階段定期更新、重新連線與切回分頁時檢查變更，桌面版每 30 分鐘檢查一次；更新也可能使顯示恢復為 DuDuClaw。

## 顯示範圍與固定的原廠標示

儀表板使用名稱與 Logo，涵蓋吉祥物位置、登入與歡迎頁、網頁標題、favicon 和 LINE QR 海報。通道頁尾、OTP 與 OAuth 頁面使用下發的名稱，產品文案支援繁體中文、英文、日文。法律聲明與隱私連結保留原文，CLI 與日誌維持原有名稱。

品牌生效時，關於頁依序顯示總經銷的 Logo 與名稱、[總經銷公告](distributor-notice.md)、固定的「軟體開發」區塊，包含原廠、網站、版本與授權方案。**嘟嘟數位科技有限公司 / Dudu Technology Ltd.** 與原廠網站都是編譯時常數，總經銷不能覆寫或隱藏。品牌範圍只有產品名稱與 Logo，不提供副標題、主題色、自訂公司欄位或自訂 About HTML。

桌面視窗標題、系統匣提示與更新對話框使用執行時名稱。安裝檔名稱、macOS Dock 名稱與 App 圖示仍在編譯時決定；更換這些項目需要另外打包桌面安裝檔，執行時的品牌更新不會變更它們。Logo 保留原始長寬比，完整放入顯示框。

## 唯讀整合介面

`about.get` 只在品牌有效時加上 `brand`。公開唯讀的 `GET /api/brand` 只提供 `product_name`、`logo_light`、`logo_dark`，不帶授權或客戶資訊；有效時回傳這三欄的頂層物件，無效時回 `null`，表示使用原本的 DuDuClaw 識別。

`about.get` 帶有 `brand_revision`；傳入 `{ "brand_revision_only": true }` 時只回傳這個欄位。`/api/brand` 以 `X-Brand-Revision` 標頭提供相同版本，支援 ETag、`If-None-Match`／304 與 60 秒公開快取。每個 IP 每分鐘最多 30 次，條件式請求也計入；超限回 429 與 `Retry-After: 60`。
