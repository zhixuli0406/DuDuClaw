# 個人版與企業版

DuDuClaw 預設以個人版執行，裝上企業方案的授權金鑰後切換成企業版。兩個版本用同一個核心，這頁列出差在哪裡，方便判斷哪一個適合你。

原則：免費核心不閹割。兩個版本的差別在數量，以及多人協作的管理介面，AI 員工能做的事一樣多。

## 對照表

| 項目 | 個人版 | 企業版 |
|---|---|---|
| AI 員工數 | 沒有硬上限，超過 3 位時儀表板會輕輕提示 | 自架沒有硬上限，授權可以另訂上限 |
| 同時執行的目標任務 | 2 個，其餘排隊 | 不限 |
| OS 原生感知員工 | 1 位 | 不限 |
| 成員帳號、部門、角色權限 | 沒有（單一擁有者） | 有 |
| 經銷商管理、身分解析、Wiki 信任治理、可靠性報表 | 沒有 | 有 |
| 本機免登入（在本機上不用輸入密碼） | 可以開啟 | 不適用 |
| 付費產業板模 | 授權內含時可用 | 可用 |
| runtime、通道、記憶、技能、MCP 工具、審批、沙箱、電腦操作 | 全部都有 | 全部都有 |

補充：

- 個人版的限制是預設值，只計算當下正在跑、正在登記的項目，沒有拿掉任何功能。
- 本機免登入只在「只監聽本機」的個人版上運作。放在反向代理後面，或綁在網路位址上，就不會啟用。
- 雲端託管方案另有各自的額度。這頁談的是自架安裝，版本跟著你裝的授權金鑰走。

## 版本怎麼決定

版本跟著已安裝的授權走。沒有授權金鑰就是個人版，企業方案的金鑰會把儀表板和伺服器切到企業版。移除金鑰會回到個人版，資料不會被刪。

## 升級方式

1. 向授權總經銷取得授權金鑰（商用授權原廠不直接販售，見 [LICENSING.md](../../../LICENSING.md)）。
2. 開啟儀表板，進入「管理 → 進階設定 → 授權」（指令面板 ⌘K 也找得到），也可以直接開 `/app/system/license`。
3. 貼上金鑰並啟用。頁面會顯示方案，版本立即切換。

個人版上若有項目提示「企業版提供」，升級同樣在這個授權頁完成。
