# 従業員のブラウザーを閲覧する

ダッシュボードにログインして `/computer/<従業員ID>` を開きます。この画面は、
従業員の設定、ファイル、記憶、会話へのアクセス権を追加しません。

直接割り当てられたアカウントは従来の表示・操作権限を使います。部下の関係から
アクセスする管理者は、マスク済み画像の閲覧と、そのセッションの終了だけが
可能です。未加工の配信、操作の引き継ぎ・返却、安全停止の解除、ログイン状態の
削除は許可されません。

チーム閲覧には Enterprise と、会話履歴と共通の
`[people] manager_team_history` 設定が必要です。現在の有効期間に対象の部下が
開始したセッションだけを表示します。同じ AI 従業員を共有していても、別の
人のセッションは公開されません。各リクエストで権限を確認し、設定の無効化、
閲覧者の停止、部下の削除、割り当て権限の引き下げを反映します。

画面が表示されている間は2秒ごとに更新します。全閲覧者でキャッシュを共有し、
新しい画像の取得は最大5秒に1回です。従業員の操作を待たせず、停止中の
ブラウザーを再開しません。古い画像には時刻を表示し、新しい要求が拒否された
場合は画像を消します。安全停止時は、それ以前の画像も全体をマスクします。

マスクの対象はパスワード、支払い欄、機密ウィンドウです。ページ内の名前や
メールなど、すべての個人情報を除去するものではありません。閲覧は監査に
記録されますが、画像は保存しません。記録の対象は実際に開始した部下だけです。
同じ閲覧者・セッションの繰り返し要求は1分単位でまとめます。閲覧要求には
人数別の上限がありますが、終了操作には適用しません。

終了の確認は表示中のセッションに結び付きます。終了後に別のセッションが
開始しても、以前の確認で新しいセッションを終了できません。

macOS ローカルブラウザーは別機能であり、そのページをチーム閲覧で公開しては
いけません。制御された Docker・画面テストは、各 OS や実サービスでの検証とは
区別します。
