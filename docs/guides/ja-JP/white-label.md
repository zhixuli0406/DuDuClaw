# 総代理店の製品名とロゴ

v1.78.0 から、総代理店の顧客はライセンスのティアに関係なく製品名とロゴを受け取れます。gateway は現在のサブスクリプションに対応するブランドを自動的に取得し、検証します。オープンソース版とライセンス未設定の環境にはサブスクリプションがなく、元の DuDuClaw ブランドを使用します。

顧客によるブランドファイルのインストールや設定変更は不要です。設定、HTTP、RPC に顧客が名前やロゴを変更するための入口はありません。旧 `branding.json` と `branding.bundle.json` は無視されます。ブランドの変更や解除は総代理店へ依頼してください。

## ブランド更新の受け取り

ブランドは、署名の検証、現在のライセンスとのサブスクリプションの完全一致、有効期限とオフライン猶予の確認を通過した場合だけ有効になります。有効なブランドがない場合は DuDuClaw を表示します。取得や文書の検証に失敗しても起動は妨げません。

更新に失敗しても、現在のライセンスが有効で、サブスクリプションが一致する間は検証済みブランドを保持します。総代理店による明示的な解除、ライセンスの失効、サブスクリプションの変更、キャッシュ文書の検証失敗でブランドを無効にします。ダッシュボードはセッションの定期更新、再接続、タブへの復帰時に変更を確認し、デスクトップは 30 分ごとに確認します。更新によって元の DuDuClaw 表示に戻る場合もあります。

## 表示箇所と固定の開発元表記

ダッシュボードのマスコット位置、ログイン、ウェルカム画面、ページタイトル、favicon、LINE QR ポスターに名前とロゴを使います。チャンネルのフッター、OTP、OAuth ページでも配信された名前を使い、製品文案は繁体字中国語、英語、日本語に対応します。法的な表記とプライバシーリンクは原文を保持し、CLI とログの名前は変わりません。

ブランドが有効な About ページは、総代理店のロゴと名前、[総代理店情報](distributor-notice.md)、固定の「ソフトウェア開発」欄の順に表示します。開発元、ウェブサイト、バージョン、ライセンスタイプを掲載し、**嘟嘟數位科技有限公司 / Dudu Technology Ltd.** と開発元サイトはコンパイル時定数です。総代理店は変更も非表示にもできません。ブランドの対象は製品名とロゴだけで、サブタイトル、アクセントカラー、独自の会社情報、カスタム About HTML は含みません。

デスクトップのウィンドウタイトル、トレイのツールチップ、更新ダイアログには実行時の名前を使います。インストーラー名、macOS Dock 名、アプリアイコンはコンパイル時に決まります。変更には別途デスクトップインストーラーの作成が必要で、実行時のブランド更新では変わりません。ロゴは元の縦横比を保持し、表示枠内に収めます。

## 読み取り専用の連携 API

`about.get` はブランドが有効なときだけ `brand` を含みます。公開の読み取り専用 `GET /api/brand` は `product_name`、`logo_light`、`logo_dark` だけを返し、ライセンスや顧客情報は含みません。有効な場合はこの 3 フィールドのトップレベルオブジェクトを返し、無効なら `null` を返して元の DuDuClaw 表示を使います。

`about.get` は `brand_revision` を含み、`{ "brand_revision_only": true }` ではこのフィールドだけを返します。`/api/brand` は同じ値を `X-Brand-Revision` ヘッダーで返し、ETag、`If-None-Match`／304、60 秒の公開キャッシュに対応します。条件付きリクエストも含めて IP ごとに毎分 30 回までで、超過時は 429 と `Retry-After: 60` を返します。
