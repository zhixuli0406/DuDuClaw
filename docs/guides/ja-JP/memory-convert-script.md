# 簡体字の記憶を繁体字に変換する（v1.84.0）

v1.84.0 より前は、AI 社員が自分で書く記憶（重要な事実、会話の記憶）がモデルの出力した字体のまま保存されていました。そのため、普段は繁体字中国語を使うインストールでも、簡体字の記憶が混ざることがありました。v1.84.0 からは「記憶の言語」設定が新しい記憶の言語を決め（[ダッシュボード設定の対応表](dashboard-settings.md#記憶の言語とバックグラウンド処理v1840)を参照）、繁体字中国語の出力は保存前に字体をそろえます。アップグレード前に保存された記憶はそのままです。既存の記憶を変換するには `duduclaw memory convert-script` を使います。

このコマンドは、DuDuClaw を動かしているマシンで管理者が実行するためのものです。`duduclaw --help` には表示されません（`memory` コマンドグループは非表示です）が、以下のとおり実行できます。

## 変わるもの・変わらないもの

- 変換対象は `<home>/memory.db` 内の 2 種類のテキスト、重要な事実と記憶エントリーだけです。wiki やナレッジのページ、会話の要約、固定された指示には触れません。
- 変換は「簡体字にしかない文字」の固定表による 1 文字ずつの置き換えです。モデルは呼ばず、翻訳もしません。英語や日本語の記憶はそのままで、文脈によって繁体字の形が変わる文字も変更しません。
- 日本語の仮名を含むエントリーは丸ごとスキップし、`skipped_japanese` として数えます。
- URL（`scheme://…`、`mailto:`、`www.`）、Markdown のリンク先、インラインコード、コードブロックはそのまま残します。
- 作り直すのは、内蔵の n-gram ハッシュ埋め込みで作ったベクトルだけです。ほかの埋め込みモデルで作ったベクトルは消去され、そうした記憶は再びベクトルが作られるまで類似度の照合に使われません（該当する場合は出力で案内します）。

## 変換される AI 社員

| 指定 | 動作 |
|---|---|
| `--all` | 記憶の言語の判定結果がちょうど `zh-TW` のすべての社員。それ以外の社員は判定された言語とともにスキップとして表示します。社員のディレクトリがない記憶空間もスキップします（その場合は `--agent` を使ってください）。 |
| `--agent <id>` | その社員の記憶を変換します。判定結果が `zh-CN` または日本語の場合は、`--force-language-mismatch` を付けない限り拒否します。`en` に設定された社員や、言語が判定されない社員は、追加のフラグなしで変換します。 |

言語の判定順は新しい記憶と同じです。社員自身の記憶の言語 → 全体の記憶の言語 → 社員の返信言語（または全体の既定の言語）。

## 手順

1. まずプレビューします。`--yes` を付けなければ、件数を数え、変換前後の例を最大 10 件表示するだけです。

   ```bash
   duduclaw memory convert-script --all
   ```

   社員ごとに `alice: preview key_facts=12, memories=40, changed=52, skipped_japanese=1, embeddings_cleared=0` のような 1 行が出ます。

2. 変換を実行します。

   ```bash
   duduclaw memory convert-script --all --yes
   ```

   最初の変更の前に復元ファイルを書き出し、そのパスを表示します（`Restore file: …`）。ファイルは `<home>/backups/memory-convert-script-<UTC 時刻>-<社員>.jsonl` で、所有者だけが読めます。社員ごとに 1 つのトランザクションで変換し、1 人が失敗してもほかの社員は続行し、最後にエラーを返します。

3. 元に戻す場合：

   ```bash
   duduclaw memory convert-script --restore <home>/backups/memory-convert-script-…jsonl
   ```

   復元はファイル全体を一括で行い、すべて成功するか何も変えないかのどちらかです。変換後に 1 件でも編集されていれば、復元は拒否されます。

## フラグ

| フラグ | 意味 |
|---|---|
| `--agent <ID>` | この社員のエントリーだけを変換します。 |
| `--all` | 記憶の言語が繁体字中国語と判定されるすべての社員。 |
| `--restore <FILE>` | 以前の変換を元に戻します。`--dry-run`、`--yes`、`--force-language-mismatch` とは併用できません。 |
| `--force-language-mismatch` | `--agent` と併用する場合のみ：社員が簡体字中国語や日本語に設定されていても変換します。 |
| `--dry-run` | プレビューのみ。`--yes` と同時に指定するとプレビューが優先されます。 |
| `--yes` | 変換を実行します。 |

`--agent`、`--all`、`--restore` のうち、ちょうど 1 つを指定する必要があります。

## 制限

- AI 社員のセッション内では実行を拒否し、セキュリティ監査ログに `memory_script_conversion_refused` を記録します。社員が自分のシェルツールから起動することもできません。実行した変換と復元は `memory_script_converted`、`memory_script_restored` として記録します。
- 置き換わるのは表にある文字だけです。どちらの字体でも同じ文字で書かれた大陸の言い回しは、そのまま残ります。
- ページと要約は変換しません。v1.84.0 以降に作られるものは記憶の言語の設定に従って書かれます。
