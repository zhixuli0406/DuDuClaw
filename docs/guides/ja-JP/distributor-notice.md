# About ページの総代理店情報

総代理店向けの DuDuClaw ビルドでは、ダッシュボードの About ページ（`/about`）に、正規総代理店の情報ブロックを 1 つ表示できます。位置は固定のベンダー表記ブロックの上です。公開ビルドにはこのブロックがなく、About ページと `about.get` の応答は従来どおりです。

このブロックは**ビルド入力**です。総代理店向けビルドを作るときに HTML が gateway のバイナリに組み込まれます。インストール済みのシステムでは、設定・RPC・ファイルのどれを使っても変更できないため、エンドユーザーが別の内容に差し替えることはできません。その代わり、内容を変えるには新しいビルドを作って配布し直す必要があります。

ホワイトラベル機能（製品名・ロゴ・色の変更）は削除されたままです。[white-label.md](white-label.md) を参照してください。このブロックは、ページ上の製品名、ベンダー表記、バージョン、ライセンス階層を変更しません。

## ビルド入力

```bash
DUDUCLAW_DISTRIBUTOR_NOTICE_PATH=/absolute/path/to/notice.html \
  cargo build --release -p duduclaw-cli
```

この変数は `crates/duduclaw-gateway/build.rs` が読み取ります。

- 未設定：総代理店情報なし（すべての公開ビルド）。
- 設定あり：通常ファイルを指す絶対パス（シンボリックリンクは拒否）、UTF-8（先頭の BOM は除去）、**埋め込み画像を含めて** 64 KB 以下である必要があります。変数が空文字列、ファイルが存在しない、その他の規則違反の場合は、理由を示してビルドが失敗します。
- ファイルまたは変数が変わると cargo が再ビルドします。
- HTML はビルド時にサニタイズされます（規則は下記）。除去された内容は cargo の出力に `warning: distributor notice: …` として列挙されます。表示できる内容が何も残らない場合、またはサニタイズ後に 64 KB を超えた場合（各リンクに `rel` と `target` が付きます）、ビルドは失敗します。

この入力は `DUDUCLAW_INSTALLATION_POLICY_PATH` とは別です。インストールポリシーはチャネル・runtime・プロバイダのブロックにのみ使い、識別情報を含めてはいけません。

## 残る HTML

- 要素：`p`、`br`、`h1`–`h4`、`ul`、`ol`、`li`、`strong`、`em`、`u`、`s`、`a`、`blockquote`、`code`、`pre`、`hr`、`img`、`div`、`span`、`table`、`thead`、`tbody`、`tr`、`th`、`td`。`<script>` と `<style>` は中身ごと除去され、それ以外の要素はタグを除去してテキストを残します。
- 属性：`a[href]`、`img[src]`、`img[alt]` のみ。`style`、`class`、`id`、すべての `on*` ハンドラは除去されます。コメントも除去されます。
- リンク：絶対 URL の `http://`、`https://`、`mailto:` のみで、`ユーザー:パスワード@` を含まないもの。すべてのリンクに `rel="nofollow noopener noreferrer" target="_blank"` が付きます。
- 画像：`data:image/png`、`data:image/jpeg`、`data:image/webp` の base64 URI のみで、中身が宣言した形式と一致し、1 枚 512 KB 以下（通常は文書全体の 64 KB 上限が先に効きます）。SVG と外部画像は除去されます。

gateway は組み込まれた HTML を最初に返す前にもう一度サニタイズします。2 回目で拒否された場合、`about.get` はこのフィールドを含めず、gateway が警告を記録します。

## ダッシュボードでの表示

- ベンダー表記ブロックの上にカードを表示し、固定の見出し「総代理店情報」と説明「正規総代理店による提供」を付けます（中国語・英語の画面では各言語の表記）。見出しは製品側の文言で、総代理店の内容には含まれません。
- 内容は `sandbox="allow-popups allow-popups-to-escape-sandbox"` の iframe の中だけに表示されます。スクリプトは実行できず、オリジンは不透明で、フォーム送信やページ全体の遷移もできません。リンクは新しいタブで開きます。iframe 内のコンテンツセキュリティポリシーがすべてのネットワーク要求を止めるため、画像は data URI で埋め込む必要があります。
- iframe の高さは 280 px 固定で、長い内容は中でスクロールします。スクリプトのない iframe は内容の高さを伝えられないため、高さを固定しています。
- iframe はダッシュボードのライト／ダークテーマに従います。総代理店の内容自体のスタイルは除去され、ダッシュボードの基本スタイルが適用されます。

## ビルドの確認

ログイン済みのダッシュボード接続から `about.get` を呼び出します。総代理店向けビルドは `distributor_notice`（サニタイズ済み HTML）を返し、公開ビルドにはこのキーがありません。
