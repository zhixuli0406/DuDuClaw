# 物理タッチポイントガイド：QR卓上カード、NFCタグ、LINE Touch

> 対象：AIスタッフをLINEに配置する店舗と導入パートナー。目標：店内でお客様が一度スキャンまたはタッチするだけで、すぐにあなたのAIスタッフとの会話を始められるようにする。
> 前提条件：チャンネルページですでにLINE公式アカウントが連携されていること（チャンネルページ→「LINE友だち追加QR」（LINE 加好友 QR）で自分のQRコードが表示されれば完了）。

## 1. QR卓上カード・ポスター（最低コスト、5分）

1. ダッシュボード→チャンネル→**「LINE友だち追加QR」**（LINE 加好友 QR）。
2. 「ポスターを印刷」（列印海報）をクリックしてそのまま印刷（ブラウザ印刷でPDF保存も可能）、または「リンクをコピー」（複製連結）して自分のデザインに貼り付ける。
3. カウンター、テーブル、パッケージ、名刺などに設置する。お客様がコードをスキャンすると友だち追加され、そのまま会話が始まる。1対1の返信はLINE Reply APIを使うため**無料**。

## 2. 自作NFC卓上カード（タッチするだけで会話開始）

台湾の店舗ではすでに「Googleクチコミ NFCステッカー」が広く使われている。同じ仕組みをあなたのAIスタッフに置き換えるだけでよい。

| 材料 | 説明 | 参考コスト |
|---|---|---|
| NFCタグ | NTAG213（144バイト、URL1本を書き込むには十分） | 小売で1枚あたりNT$22〜35程度、量産カスタム（印刷込み）ならさらに安い |
| 書き込みアプリ | NFC Tools（iOS/Android、無料）、または任意のNDEFライター | 無料 |
| 卓上カード | アクリルスタンド＋ステッカー、または耐金属NFCステッカー単体 | 数十〜百数十元 |

手順：
1. チャンネルページ→「LINE友だち追加QR」（LINE 加好友 QR）→**リンクをコピー**（NFCに書き込むのはこのURL）。
2. NFC Tools→Write→Add a record→URL→貼り付け→Write。スマートフォンをタグに近づければ書き込み完了。
3. **タグのロック（Lock）を推奨**。書き換えを防止するため。
4. 実機テスト：別のスマートフォンを近づける。友だち追加ページが直接開けば成功。

卓上カードにはQRとNFCの両方を用意することを推奨する。旧型iPhoneや一部のAndroid端末はNFC対応状況が異なるため、QRがフォールバックになる。

## 3. LINE Touch（LINE公式NFCプログラム）

LINE公式の「タッチ」プログラム。自作NFCとの違いは、タグがLINEから発行される点、遷移先をOA管理画面からいつでも変更できる点（物理タグの交換が不要）、LINE MINI Appへの誘導も可能な点、そして公式のマーケティングリソースが得られる点にある。

**準備状況チェックリスト（2026年8月時点の情報）**：

- [ ] **ブルーバッジ認証済み公式アカウント**：LINE Touchの前提条件。自分で申請する場合は回答まで最長30日、通常は10営業日程度。代理店経由の迅速審査なら約5日。
- [ ] **タグの調達**：LINE Touch NFCタグは**2026年9月末**からOA Shopで購入可能になる予定（2種類のサイズ：A6と54×85mm）。タグはLINEからのみ購入可能で、自作はできない。
- [ ] **管理画面の設定**：OA管理画面（2026年7月22日からLINE Touch機能エリアが開放）で遷移先を紐付ける。友だち追加、指定メッセージ、またはMINI Appから選ぶ。
- [ ] **遷移先の推奨**：まずは「友だち追加」に直接誘導する（本ガイド第1節と同じリンクの公式版）。MINI Appができたら遷移先をアップグレードする。

自作NFCとLINE Touchの選び方：**今すぐ必要なら自作**（本ガイド第2節、当日中に稼働可能）。**管理画面から内容を変更したい、またはMINI Appに接続したいならLINE Touch**（9月のタグ販売開始を待つ）。両者は排他的ではなく、まず自作で始めてタグが届いたら切り替えることもできる。

## 4. 導入パートナー（販売代理店）向け補足

- 卓上カードは共同ブランド化も可能：台湾のNFC印刷業者（カスタムステッカー／アクリルプレート）に一括発注する。卓上カード1枚あたりのCOGSは約NT$100〜200で、導入パッケージの特典または追加購入オプションとして使える。
- 出荷前に自分のスマートフォンで各ロットのタグを実機テストする（書き込み＋ロック＋遷移の3ステップ）。
