# パーソナル版とエンタープライズ版

DuDuClaw は既定でパーソナル版として動作し、エンタープライズ系プランのライセンスキーを入れるとエンタープライズ版に切り替わります。両者は同じコアを使います。このページでは違いを一覧にして、どちらが合うか判断できるようにします。

原則: 無料のコアは機能を削りません。違いは数量と、複数人向けの管理画面にあり、AI 社員にできることは同じです。

## 比較表

| 項目 | パーソナル版 | エンタープライズ版 |
|---|---|---|
| AI 社員の数 | 厳密な上限なし。3 人を超えるとダッシュボードに控えめな案内を表示 | セルフホストでは厳密な上限なし。ライセンスで上限を定める場合あり |
| 同時に実行するゴールタスク | 2 件、残りは待ち行列 | 無制限 |
| OS ネイティブ感知の社員 | 1 人 | 無制限 |
| メンバーアカウント、部門、ロール権限 | なし（オーナー 1 人） | あり |
| 販売代理店管理、ID 解決、Wiki 信頼ガバナンス、信頼性レポート | なし | あり |
| ローカル自動ログイン（そのマシン上ではパスワード不要） | 有効にできる | 対象外 |
| 有料の業種テンプレート | ライセンスに含まれる場合に利用可 | 利用可 |
| ランタイム、チャネル、記憶、スキル、MCP ツール、承認、サンドボックス、コンピュータ操作 | すべて利用可 | すべて利用可 |

補足:

- パーソナル版の制限は既定値です。いま実行中、登録中のものを数えるだけで、機能を取り除くものではありません。
- ローカル自動ログインは、ローカルマシンのみで待ち受けるパーソナル版でのみ動作します。リバースプロキシの背後やネットワークアドレスに公開した場合は無効です。
- クラウドホスト型プランには別の割り当てがあります。このページはセルフホスト環境を対象とし、版は入れたライセンスキーに従います。

## 版の決まり方

版はインストール済みのライセンスで決まります。キーがなければパーソナル版です。エンタープライズ系プランのキーでダッシュボードとサーバーがエンタープライズ版に切り替わります。キーを外すとパーソナル版に戻り、データは消えません。

## アップグレード方法

1. 正規販売代理店からライセンスキーを入手します（商用ライセンスは開発元が直接販売しません。[LICENSING.md](../../../LICENSING.md) を参照）。
2. ダッシュボードの「システム設定」アプリで「ライセンス」ページを開きます。`/app/system/license` を直接開くこともできます。
3. キーを貼り付けて有効化します。プランが表示され、版はすぐに切り替わります。

パーソナル版で「エンタープライズ版で利用できます」と表示された項目も、同じライセンスページでアップグレードします。
