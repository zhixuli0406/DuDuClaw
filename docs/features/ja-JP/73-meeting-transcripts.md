# 会議の文字起こし

[English](../73-meeting-transcripts.md) · [繁體中文](../zh-TW/73-meeting-transcripts.md)

Meet、Zoom、Teams などからダウンロードした録音・録画を、時刻付きの台湾繁体字中国語 Markdown と JSON に変換します。ライブ会議への参加・録画や Drive 録画の直接取得は行いません。OAuth 権限は追加しません。

## 大きな録音をアップロード

コントロールパネルの「会議の文字起こし」で、利用できる社員と録音・動画を選択します。管理者以外は直接紐付けされ、選択可能かつ Operator／Owner 権限のある社員のみを選べ、メイン・既定の社員や管理者専用の機器社員は利用できません。8 MiB ごとの分割アップロードを SHA-256 で検証します。中断後は同じファイルを選んで再開できます。未完了のアップロードは新しい分割を受信しないまま 2 時間経過すると失効します。

WebCodecs が利用できる場合、MP4／MOV の AAC-LC 音声を抽出し、約 48 kbps のモノラル AAC に変換します。WebM、未対応コーデック、変換エラーの場合は元のファイルを送信します。画面に選択した方法を表示します。解析には BSD-3-Clause の mp4box.js をバージョン固定で使用します。すべての動画の変換を保証するものではありません。

一覧に待機、準備、分割ごとの文字起こし、完了、失敗、キャンセルを表示し、完了後は Markdown／JSON を取得できます。キャンセルは次の分割処理を停止します。送信済みの処理は終了して利用量を記録するため、発生済みの料金は取り消せません。

## 会話から利用

```json
{"source_path":"meeting.mp4","language_hint":"zh-TW","write_wiki":false}
```

`meeting_transcribe` は自分の添付ファイルを受け付け、すぐに `job_id` と状態を返します。`meeting_transcribe_status {"job_id":"…"}` で状況を確認し、`meeting_transcribe_cancel {"job_id":"…"}` でキャンセルできます。他の社員の仕事と存在しない仕事は同じエラーになります。ツールはゲートウェイが認証した社員プロセスのみで利用できます。

`meeting_upload_link {}` は元の会話に紐付く一回限りのリンクを作成します。利用できる添付パスがない場合もリンクを返します。30 分以内にアップロードを開始してください。開始後はリンクは最大 24 時間有効ですが、アップロードは 2 時間の無通信で失効し、完了後はリンクが無効になります。ランダムな token はハッシュのみ保存し、そのアップロード以外の API を許可しません。HTTPS の `[dashboard] public_url` が必要で、リバースプロキシのサブパスにも対応します。未設定の場合はコントロールパネルをご利用ください。

通知には録音時間、話者数、ファイル名を含めます。Telegram、Discord、Slack は元のボット・スレッドへ Markdown を添付でき、LINE は添付の取得方法を案内します。WebChat は元の会話に保存し、再読み込みで表示します。元の送信先を検証できないチャネルでは通知エラーを記録し、別のボットに切り替えません。間隔を延ばしながら最大 5 回再試行し、通知できなくても結果はコントロールパネルから取得できます。

## 設定と制限

管理者は「設定 → 音声」でサービスとモデルを選びます。サイズ、共有領域、並列数は次の設定です。

```toml
[transcription]
engine = "gemini" # gemini | whisper; google_stt は未実装
# model = "gemini/<音声と構造化出力に対応する登録モデル>"
max_bytes = 4294967296 # 1～4294967296、既定 4 GiB
staging_quota_bytes = 10737418240 # 既定 10 GiB、仕事とアップロードで共有
media_memory_limit_bytes = 2147483648 # 2 GiB
max_concurrent_jobs = 1 # 1 または 2
```

Gemini は指定モデル、未指定なら ModelRegistry の音声・構造化出力対応モデルを使います。Whisper は既存の OpenAI 認証情報を使い、話者を識別しません。Gemini の誤認識や分割間の話者ラベル変更に注意してください。`google_stt` は明示的に未対応と返し、別サービスへ切り替えません。社員は管理者のサービス選択を変更できません。

動画や長い録音にはホストの **ffmpeg と ffprobe** が必要です。約 30 分ずつ、最大 96 分割／48 時間まで処理します。ffmpeg がない場合、サービスのサイズ制限内で、ffprobe が 30 分以下と確認できた音声のみ直接送信できます。長さが不明または超過する録音は拒否します。OpenCC `s2twp` により台湾の繁体字・語句へ変換しますが、外国語の翻訳ではありません。

共有領域は元ファイルのコピーと変換音声を事前予約し、直接アップロードではアップロード元も計上します。終了後はアップロード元と一時音声を削除し、文字起こし結果を残します。通常の社員添付として提出した元ファイルは削除しません。ゲートウェイ再起動時は未完了の仕事を最初からやり直し、固定の仕事 ID で出力します。サービス料金が重複する場合があり、記録済み料金を保持して累計します。中断中の処理料金は測定できないことがあります。

社員の一時停止は新規受付と後続の分割処理を止めます。権限、外部送信、マスキング設定が変わると既存の仕事を停止し、再提出を求めます。追加承認が必要な設定ではウェブ／リンクのアップロードを拒否します。ウェブアップロードの対話式承認は未実装で、承認を省略しません。

## CLI とプライバシー

```sh
duduclaw meeting transcribe ./meeting.mp4 --out ./transcripts
```

ローカル操作者の CLI は同期処理です。AI 社員のセッションは拒否し、共通 Bash 操作者コマンドガードも社員と未検証の呼び出し元を拒否します。社員は会議 MCP ツールを使ってください。`write_wiki: true` は未対応です。結果を確認後、既存の知識ベースツールを使ってください。

音声は選択したサービスへ送信されます。Gemini 無料 API の内容は製品改善に使われる場合があるため、利用条件と会議の機密性を確認してください。設定されたマスキングは保存前の本文・元ファイル名に適用し、失敗時は保存しません。すでに送った音声内の機密情報は取り除けません。社員設定で全体のマスキングを無効にはできません。

実サービス品質、長時間動画のブラウザ変換、各 OS の ffmpeg、実チャネルの添付、大容量ネットワーク再開は別途検証が必要です。mock テストはこれらの実機検証を意味しません。

## 権限と制限

参照・ダウンロードは Viewer、変更は Operator が必要です。待機中のアップロードはファイルサイズ＋64 KiB を予約し、利用者ごと・社員ごとに最大 2 件、総容量の半分までです。キャンセル・失効で予約を解放します。承認と外部送信はゲートウェイの私有コピーの SHA-256 とサイズに紐付き、実行時にも検証します。保存済み出力は実バイト数を計上します。AI への状態応答はメタデータと添付パスのみで、本文プレビューはコントロールパネル専用です。通知に本文抜粋は含めません。

仕事ごとの上限は 200,000 段、本文と話者名の合計 32 MiB、出力 256 MiB です。アップロードとダウンロードの同時実行枠を分離し、利用者ごとに転送は 1 件、アップロード速度は 30 秒間で毎秒 32 KiB 以上を必要とします。公開リンクは token 検索前に IP・全体制限、検証後にリンクごとの制限を適用します。監査に token・鍵・本文・機密パスは記録しません。異常な利用量はローカルで算出した推定値に置き換えます。

Unix のメディア子プロセスは CPU 時間とファイル記述子 256 個を制限します。Linux はアドレス空間を制限し、macOS は AS／DATA 制限を試みます。両 OS で 500 ms ごとに RSS を監視し、rlimit が使えない場合も継続します。`media_memory_limit_bytes`（既定 2 GiB）を超えるか RSS を確認できない場合は、プロセスグループを終了して仕事を失敗させます。

Whisper の料金はローカルで計測した分割音声の長さを使います。Gemini の音声使用量がローカルの長さに対して毎秒 16 tokens 未満なら推定値へ置き換えます。会議ツール監査には添付ラベルと検証済み仕事 ID の先頭のみを保存し、アップロード URL と結果本文は保存しません。
