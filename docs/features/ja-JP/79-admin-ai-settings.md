# 管理者 AI による設定変更

管理者は、自分専用の AI アバターに依頼して、複数の AI 従業員の日常設定をまとめて読み取り、変更できます。この機能は初期状態ではオフです。管理者がリスク説明を読み、「理解しました」と確認したうえで「設定」から有効にします。有効にした人と日時が記録されます。

## 利用できる人と場所

初期パスワードを変更済みの有効な管理者だけが、自分に一意に割り当てられた AI アバターを通じて、本人が会話に参加している間に利用できます。プライベートチャットとサインイン済み WebChat では読み取りと変更提案ができます。グループチャットは読み取りのみで、スケジュールのプロンプト本文とスキルの説明は表示されません。保護モードでは利用できません。スケジュール実行、委任、バックグラウンドのターンも対象外です。

対象は閲覧可能な従業員です。終了済みの従業員、一時的なチーム役割、他の人の個人用従業員は対象外です。

## 変更できる設定

表示名、アイコン、呼び出し名、有効／一時停止、返信言語、メイン／予備モデル、思考の深さ、1 回の実行時間の上限、最大ステップ数、無操作時のタイムアウト、定期起動、プロンプトのみの時刻指定スケジュール、インストール済みスキルの有効／無効を提案できます。モデルは現在の実行エンジンで動作する必要があります。時間とステップ数は全体上限内に限られます。定期起動ではオン／オフ、時刻、間隔、タイムゾーンを設定できます。この機能ではワークフロー付きスケジュールや即時実行は扱いません。

次の設定はダッシュボードでのみ変更できます。

| 設定 | ダッシュボードに限定する理由 |
|---|---|
| ツールとデータへのアクセス権限 | AI が実行できる操作を決めるため。 |
| 従業員の操作権限と利用可能なチャネル | 委任、従業員作成、スケジュール、スキル操作を保護するため。 |
| サンドボックス、ネットワーク隔離、ファイル保護 | 実行隔離とファイル保護を変えるため。 |
| 実行エンジン、予備エンジン、バックグラウンドサービス | ツールと隔離方式が変わり、会話が別のサービスへ送られる可能性があるため。 |
| モデルアカウントと予算の引き上げ | 費用と支払い上限に関わるため。 |
| サービス ID、チャネル認証情報、公開アクセス | 同僚に代わるアクセスと外部公開の範囲を制御するため。 |
| 上司、部署、従業員 ID、主要ロール | 組織と委任権限を変えるため。 |
| 委任範囲、外部エージェント接続、認証 | 委任範囲を広げたり、本人確認を解除したりできるため。 |
| 外部ツールサーバーと接続設定 | 外部ツールや実行プログラムへの接続を変えるため。 |
| 従業員の人格と業務契約 | ダッシュボード限定の別の承認手順があるため。 |
| 従業員のアーカイブと削除 | 元に戻せない場合があるため。 |
| 外部からのスキル導入 | サプライチェーンのリスクがあるため。AI が変更できるのは導入済みスキルの有効／無効だけです。 |

## 確認と適用

変更を 1 件だけ提案した場合も確認カードが作成され、従業員、設定、変更前後の値が表示されます。有効期限は 10 分です。提案した管理者本人だけがダッシュボードの受信箱で確認または取消できます。このバージョンではチャット内確認に対応していません。

確認前に対象従業員の設定が 1 つでも変わると、提案全体が無効になります。確認後は最初の失敗で処理を停止し、それ以前の変更はロールバックせず、完了した内容を報告します。

## 監査

セキュリティ監査ログには提案、変更、無効化、拒否、機能のオン／オフが記録されます。通常の従業員設定をダッシュボードで変更した場合も、実行者と変更前後の値が記録されます。管理者はダッシュボードの「セキュリティ監査」で確認できます。
