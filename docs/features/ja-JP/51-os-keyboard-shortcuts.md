# DuDuClaw OS キーボードショートカット一覧

> DuDuClaw OS(起動可能な当番機イメージ。詳細は
> [50-duduclaw-os-appliance.md](50-duduclaw-os-appliance.md)を参照)デスク
> トップ環境の完全なキーボードショートカット早見表です。DuDuClaw を通常の
> サーバー形式でインストールし、Webダッシュボード経由で操作している場合、
> このページは関係ありません——ここで扱うのは当番機本体のデスクトップです。

## これは何か

DuDuClaw OS は起動すると、精簡されたデスクトップ環境——ホーム画面、ウィン
ドウ切り替え、ロック画面、そして初回起動時のセットアップウィザード——に直
接入ります。これらすべてはマウスなしで操作できます。本ページは「どこで有
効か」ごとにショートカットをグループ分けし、メニュー(実際にはほとんどあ
りませんが)を探し回ったり、当てずっぽうで試したりする手間を省きます。

本ページには今回新規追加されたショートカットが2つあります:**Tab**キーは
初回セットアップ中の入力欄間を移動でき、**Cmd+K**は現在どの app を使って
いても、グローバルな委任バーを呼び出せるようになりました。

## グローバル——デバイス上のあらゆる app の上で有効

このグループはシステム自体が処理し、すべての app の上に重なります——現在
サードパーティの app がキーボードフォーカスを占有していても、これらのキ
ーは変わらず機能します。さらに、AI エージェントが機器を操作している最中
でも、構造的にこれらのキーをトリガーしたり横取りしたりすることは一切でき
ません。これらは実機のキーボードの前に座る人間だけのために予約されていま
す。

| キー | 動作 |
|---|---|
| **Cmd+Esc** | 緊急停止。AI エージェントが画面上で現在行っているあらゆる操作を即座に中止し、制御を人間に戻します。画面がどんな状態であっても必ず機能します。 |
| **Cmd+Return** | AI エージェントが画面操作を終えた後、制御を人間に戻します——上記「緊急停止」の、より穏やかで意図的なバージョンです。 |
| **Cmd+K** | 現在使用中の app の上から委任バーを呼び出します——AI スタッフにすばやくタスクを委任するための入り口です。**今回新規追加。** |
| **Alt+Tab**(または**Cmd+Tab**) | 「最近使用した順」でウィンドウを切り替えます。修飾キーを押したまま Tab を連続して押すと順に巡回し、離すとその時点でハイライトされているウィンドウに切り替わります。同時に**Shift**を押していると逆方向に巡回します。 |
| **Esc**(ウィンドウ切り替え中) | 今回のウィンドウ切り替えをキャンセルし、元のウィンドウにとどまります。 |
| **Cmd+Q** | 現在最前面のウィンドウを閉じます。 |

## シェルインターフェース——ホーム画面、委任バー、コントロールセンター

このグループは DuDuClaw 自身の画面がキーボードフォーカスを持っている場合
にのみ有効です(フォーカスがサードパーティの app にある場合は、上記のグ
ローバル**Cmd+K**を使ってください)。

| キー | 動作 | 有効な場所 |
|---|---|---|
| **Cmd+K** | 委任バーを開閉します。 | ホーム画面 |
| **Esc** | 現在開いているパネル——委任バー、通知センター、コントロールセンターのいずれか(同時に開くのは常に1つだけ)を閉じます。 | ホーム画面 |
| **Cmd+L** | 画面を即座にロックします。電源メニューから「ロック」を選んだ場合と同じ効果です。 | ホーム画面 |

## 初回セットアップ

DuDuClaw OS は初回起動時に短いセットアップフローを進みます——言語、ネット
ワーク、管理者アカウントの作成、そしていくつかの設定画面です。以下の3つ
のキーだけで、マウスなしに全行程を完了できます。

| キー | 動作 | 有効な場所 |
|---|---|---|
| **Enter**(↵) | 次のステップへ進みます。「続行前にサーバーとの通信が必要な」2つのステップ——管理者アカウントの作成、Wi-Fi ネットワークへの参加——では、Enter を押すとまずそのステップ自身のアクションボタン(例:「アカウントを作成」「接続」。まだ押していない場合)がトリガーされ、成功して初めて次に進みます。これは通常のログインフォームでパスワードを入力して Enter を押したときの挙動と同じ直感的な動作です。 | 初回セットアップ |
| **Esc** | 前のステップに戻ります。最初のステップでは何も起こりません——それより前にステップがないためです。 | 初回セットアップ |
| **Tab** / **Shift+Tab** | カーソルを現在のステップの次の(Shift を押していれば前の)テキスト入力欄に移動します——例えばアカウント作成ステップの氏名欄とパスワード欄の間や、Wi-Fi パスワード欄へのジャンプなどです。最後の欄で Tab を押すと最初の欄に戻ります。**今回新規追加。** | 初回セットアップ |

## ロック画面

| キー | 動作 |
|---|---|
| 任意のキーまたはクリック | パスワード入力欄を表示します(まだ表示されていない場合)。 |
| **Enter**(↵) | パスワード入力欄がまだ表示されていなければ、まずそれを表示します。既に表示されていて、かつ既に文字を入力済みであれば、ロック解除を試行します。 |
