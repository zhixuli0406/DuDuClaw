# 管理員 AI 設定

管理員可以請自己的 AI 分身一次讀取或修改多位 AI 員工的日常設定。此功能預設關閉；管理員閱讀風險說明並勾選「我了解」後，可在「設定 → 進階設定 → 委派權限」底部的「管理員 AI」卡啟用。系統會記錄啟用者與時間。

開啟開關須勾選「我了解」，關閉立即生效。「收件匣 → 管理員 AI 設定變更確認」卡會倒數十分鐘，處理結果區分完成、部分完成與已作廢；已處理卡片會在有資料時顯示「決定者」與決定時間。

## 使用資格

只有已更改初始密碼的啟用中管理員，能在本人親自參與對話時，透過唯一指派給自己的 AI 分身使用此功能。私訊與已登入的 WebChat 可讀取及提出變更。群組對話只能讀取，不會顯示排程提示全文與技能說明。受保護模式不提供此功能；排程、委派及背景回合都不符合資格。

可操作對象為目前可見的員工，不包括已終止員工、臨時團隊角色，以及指派給其他人的個人員工。

## 可修改的設定

管理員的 AI 可提出修改顯示名稱、圖示、呼叫名稱、啟用或暫停狀態、回覆語言、主要與備援模型、思考強度、單次執行時間上限、每次最多步數、閒置逾時、定時喚醒設定、純提示型時間排程，以及已安裝技能的啟用狀態。模型必須能在員工目前的執行引擎上運作；時間與步數不得超過全域上限。定時喚醒包含開關、時間、間隔與時區。此功能不支援工作流程排程或立即執行排程。

以下設定只能在儀表板修改：

| 設定 | 僅限儀表板的原因 |
|---|---|
| 工具與資料存取權限 | 決定 AI 可以執行哪些操作。 |
| 員工操作權限與可用通道 | 保護委派、建立員工、排程及技能操作。 |
| 沙箱、網路隔離與檔案防護 | 會改變執行隔離與檔案保護。 |
| 執行引擎、備援引擎與背景服務 | 切換引擎會改變工具與隔離方式，也可能將對話送到其他服務。 |
| 模型帳號與預算放寬 | 涉及費用與付款限制。 |
| 服務身分、通道憑證與公開呼叫 | 控制代表同事存取服務及對外開放範圍。 |
| 主管、部門、員工識別碼與主要角色 | 會改變組織與委派權限。 |
| 委派範圍、外部代理連線與身分驗證 | 可能放寬委派或解除身分檢查。 |
| 外部工具伺服器與連線設定 | 會改變外部工具或可執行程式的連線。 |
| 員工人格與工作合約 | 另有只能在儀表板確認的流程。 |
| 封存與刪除員工 | 可能無法復原。 |
| 從外部安裝技能 | 外部程式有供應鏈風險；AI 只能啟用或停用已安裝的技能。 |

## 檢視與套用

每次提出變更，即使只有一項，也會建立確認卡，逐項列出員工、設定、原值與新值。確認卡有效十分鐘，只有提出變更的管理員能在儀表板收件匣確認或取消；此版本不支援在聊天中確認。

確認前，只要任一目標員工的設定有變動，整批提案就會作廢。確認後若執行遇到第一個錯誤，就會停止，不回復先前已完成的項目，並回報執行結果。

## 稽核

安全稽核紀錄會記下提案、變更、作廢或拒絕，以及功能開關的變動。儀表板對一般員工設定的修改也會記錄操作者與修改前後的值。管理員可在儀表板的「安全稽核」查看。
