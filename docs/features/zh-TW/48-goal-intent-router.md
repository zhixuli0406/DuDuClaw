# 目標意圖路由器

> 當你在聊天通道裡叫 agent 做一件實際的工作，它現在會注意到，主動問你要不要把這變成一個有追蹤的目標；但它從來不會自己偷偷建立目標。要由你回覆確認詞或按下按鈕才會建立。

## 這是什麼

過去只有儀表板能啟動一個自主目標（agent 朝驗收標準工作，卡住就升級給人的那個迴圈）。在任何聊天通道裡，只要不是明確打 `/goal` 指令，一律當成普通對話處理。於是「幫我把這一季的請款單整理成報表寄出去」這種明明是一件工作、不是一個問題的訊息，得到的只是一句聊天回覆，什麼都沒被追蹤。

目標意圖路由器補上這個缺口。它讀進每一則訊息，判斷這看起來像不像在交辦一件工作，是的話回一個小選單：開始任務、先給計畫（等你核准才開始）、或繼續聊。建立目標要花 token，還會啟動一個自己跑起來的迴圈，所以路由器絕不自動出手，命中最多只產生一則等你確認的建議。這一步確認讓誤判的代價很低：最壞情況也只是多一則你順手劃掉的訊息。

## 怎麼判斷

三層由便宜到貴，跟知識路由器是同一套形狀：

1. **硬性排除（零成本）。** 指令、極短訊息、問句、命中注入掃描的訊息，以及大部分是引用回覆的訊息，一律直接放行到普通聊天。
2. **訊號分數（不用 LLM）。** 一張固定的計分表：交辦動詞、交付物名詞、多步驟措辭、期限，加分；問號、閒聊標記、簡短跟話，以及單次寫作請求（例如擬稿或回覆信件、Email、訊息），扣分。分數明顯偏低就停在聊天；高分也不會單憑分數提出建議。
3. **模型確認。** 高分與中間分數都要先請語言模型回答一個是非題：這是不是在交辦一件要跑好幾步的工作？有設定本機推理後端就在裝置端跑，雲端成本零；沒有的話就把這個問題併進 agent 本來就要生成的回覆裡，一樣不多花錢。本機模型不可用或答案解析不出來時，改由回覆本身的模型判斷；回覆沒有有效建議就維持聊天，不會卡住你的回覆。

## 確認一則建議

在 Telegram、Discord、Slack、LINE 上，建議會附三顆按鈕：🎯 開始任務／🧭 先給計畫／💬 繼續聊。所有通道也都有文字選單：回覆「開始任務」就建立任務，回覆「先給計畫」則先看計畫，回覆「繼續聊」或直接繼續說話都會取消建議。選單與按鈕依 `[general] default_language` 顯示；英文是 start task／plan first／keep chatting，日文是 タスク開始／先に計画／このまま会話。不論設定哪種語言，三語確認詞都接受，也接受外加引號與句尾標點，英文不分大小寫。`1`、`2`、`3` 只保留為舊版捷徑；如果 AI 回覆本身含編號清單，就忽略數字捷徑，當成一般聊天回答，避免把選草稿誤當成建立任務。

選「開始任務」沿用自己打 `/goal` 的建立檢查，所有存取檢查與核准關卡照樣套用。選「先給計畫」會先產出計畫，把任務停在等你核准，任何工作都還沒開始。其他回覆，或十分鐘沒回應，建議就悄悄消失。

建立後的回覆會說清楚：是因為你剛剛回了哪句話或按了哪顆按鈕才建立、要做什麼，以及 AI 員工會一步步處理，完成或卡住時在這裡回報。想取消就打開儀表板的「目標任務」頁面停止任務。如果沒有開啟自動執行，回覆會說任務已建立但不會自己開始，請找管理員協助。先給計畫的回覆也會引導你到同一頁核准、修改或停止。這些回覆不再列任務編號、指令或設定提示；自己打 `/goal` 的回覆維持原樣。

按按鈕、打 `/goal`、用儀表板建立，三條路最後都匯到同一個建立入口，驗收標準在建立當下就凍結，不管走哪條路都一樣。

## 設定

在 `agent.toml` 逐 agent 設定（或在 `config.toml` 全域設定），區塊是 `[goal_intent]`：

| 欄位 | 預設 | 意義 |
|-----|---------|---------|
| `enabled` | `true` | 總開關。留著開沒關係，因為每次命中都卡在確認這一關。 |
| `mode` | `"auto"` | `auto`（有本機模型就用，沒有就併進回覆）、`local`、`reply_tag`、或 `off`。 |
| `t_goal` | `65` | 高分等級的門檻，仍須經過模型確認才會建議。 |
| `t_gray` | `30` | 分數低於這裡停在聊天；以上的分數都須經模型確認。 |
| `cooldown_minutes` | `30` | 同一段對話裡兩次建議之間的最短間隔。 |
| `daily_cap` | `20` | 每個 agent 每個 UTC 日的建議上限。 |
| `suggest_ttl_minutes` | `10` | 一則待確認的建議等你回覆的時間上限。 |

路由器跑在存取關卡與接手攔截之後，所以它從不放寬一則訊息原本能做的事，只是替一條你本來就能自己走的路提供捷徑。
