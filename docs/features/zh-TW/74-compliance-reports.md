# 企業版合規報表

企業版的管理員可在 **稽核日誌 → 合規報表** 下載外送閘門決策、審批、行動審查與已記錄的資料來源存取，作為內部個資管理查核資料。報表方便依臺灣個人資料保護法整理證據，不代表通過法規認證，也不保證符合個資法。

## 產生報表

1. 開啟 **稽核日誌**，點選 **合規報表**。
2. 選取開始與結束日期。兩者皆以臺北日期計算，包含結束日全天；報表時間使用 UTC，查詢區間為 `[from, until)`。最多可選 366 天。
3. 選擇 CSV、Excel（`.xlsx`）或可列印 HTML。需要 PDF 時，以瀏覽器開啟下載的 HTML，選擇 **列印 → 另存為 PDF**。欄位標籤依儀表板語言提供繁體中文、英文或日文。
4. 預設不勾選 **包含未遮罩的個人資料**。管理員明確勾選後，才會包含來源紀錄中仍留存的原始值。遮罩與未遮罩匯出都會留下稽核紀錄；稽核寫入失敗時拒絕交付。
5. 點選 **產生並下載**。10,000 列上限合計所有報表區段；同一筆審批可能同時列在外送與審批區段，計為兩列。超過列數或資料量上限時整次拒絕，不會默默截斷；請縮小日期範圍後重試。

非管理員與個人版不顯示按鈕。閘道也會重新確認管理員權限與目前解析出的版本；改網址或直接呼叫 RPC 仍須通過檢查。AI 員工沒有產生此報表的 MCP 工具。

## 判讀紀錄

報表包含摘要筆數，並分列外送決策、審批、行動審查，以及已記錄的資料來源工具呼叫與偵測／遮罩事件。存取區段不代表完整存取清單。已記錄的 `db_select`、`db_query` 與 `db_tables` 呼叫只提供中繼資料，不包含 SQL 或查詢結果。外送列包含已記錄的時間、員工、目的通道或主機、資料類別、決策、核准者與原因。審批列包含種類、申請者、決策者、決策與時間。未記錄的欄位留空。審批是目前狀態的快照，不重建過去狀態：決策時間在選取區間之外時標示 `decision_outside_range`，未記錄決策時間時標示 `decision_time_unrecorded`。兩種標示都不推測該區間內曾適用的決策。

**閘門決策不等於成功外送。** 核准可能過期，工具之後可能失敗；拒絕的請求也不能用來證明資料曾離開系統。報表不重建缺少的歷史、不補列未記錄的存取，也不從訊息本文推測資料類別或核准者。未曾記錄、已輪替或依來源保存政策移除的資料不會出現。看到零筆時，請先檢查報表的來源與保存說明。

預設遮罩會對人物欄位套用同一份報表內一致的假名，目的地與原因則整欄遮罩。其他文字以既有遮罩引擎的 `general` 與 `taiwan_strict` 規則處理。偵測有範圍限制，未知或經變形的個資仍可能留存。明確選擇完整值時仍會遮罩憑證，也無法還原儲存前已遮罩的值。報表不匯出或重建當時的私有資料原始內容。

## 保存與管理

報表附保存說明。產生報表不會延長來源紀錄的保存期限、不會建立新的個資利用依據，也不會刪除來源紀錄。產生的檔案直接下載至瀏覽器，請依組織的存取權限、特定目的與保存政策管理副本；未遮罩報表應比照來源個資保護。

管理員 RPC 為 `compliance.generate`，必填 RFC3339 `from`、`until` 與 `format`（`csv`、`xlsx`、`html`）；選填 `language`（`zh-TW`、`en`、`ja-JP`，預設 `zh-TW`）與 `include_personal_data`（預設 `false`）。上界不包含在查詢內。成功回覆含檔名、內容類型、base64 檔案內容與筆數，不建立持久的共用附件。

閘門的實際保護範圍見 [安全防護](05-security-defense.md) 與 [外送資料防護](69-egress-guard.md)。

報表讀取與稽核寫入共用跨程序鎖，涵蓋輪替與追加，避免匯出時因輪替漏讀目前這一代紀錄。保留的兩代工具稽核紀錄皆以報表實際使用的有大小限制快照驗證雜湊鏈；鏈結損壞、紀錄格式錯誤或讀取／鎖定失敗時拒絕匯出。有效的舊格式前綴仍可讀取，但無法獨立驗證真實性。雜湊鏈無法證明尾端完整性，也不提供外部可信錨點的真實性保證。
