# ADR-003: 対象外としたメッセージングチャネル(Signal / 個人版 WeChat / Viber)

- Status: Accepted
- Date: 2026-07-08
- Deciders: DuDuClaw maintainers

## Context

DuDuClaw は 9 つのチャネル(Telegram、LINE、Discord、Slack、WhatsApp、Feishu、
Google Chat、Microsoft Teams、WebChat——この人数は本 ADR 執筆時点でのカウントであり、
WeCom と DingTalk は後から追加され、合計 11 チャネルとなった)を提供している。
2026-07 のチャネルギャップレビューにおいて、さらに 3 つのプラットフォームを評価し、
**意図的に対象外とした**。この決定をここに記録しておくことで、同じ選択肢が四半期ごとに
再調査されるのを防ぐ——さらに重要なことに、誰かがトレードオフを理解しないまま
リスクの高い非公式依存を出荷してしまう事態を防ぐ。

## Decision

現時点では、Signal、個人アカウント版 WeChat、Viber 向けのファーストパーティ
コネクタを**構築しない**。

### Signal

- 公式の bot API は存在しない。`signal-cli` がコミュニティによる統合パスである。
- 従来の調査結果への訂正:`signal-cli` は(リバースエンジニアリングされたプロトコル
  ではなく)**公式の `libsignal`** ライブラリを使用している。ただし、それでも駆動する
  のは*個人*の Signal アカウントであり、公認された bot プラットフォームは存在しない。
  これはレート制限やアカウント登録解除のリスクを伴い、Signal の利用規約も人間による
  利用を前提としている。
- 結論:個人アカウントブリッジが伴う運用リスクに対して ROI が低い。Signal が公式の
  bot/business API を公開した場合にのみ再検討する。
- Source: https://signal.org/docs/

### WeChat(個人アカウント)

- 個人アカウント向けの公式 API は存在せず、非公式ブリッジは常態的にアカウント
  停止(BAN)を引き起こす。
- **企業版**パス(WeCom / 企業微信)は*別個の*、公認された製品であり、公式の
  webhook + WebSocket bot サポートを持ち、両岸(中国大陸・台湾)の中小企業向け
  ユースケースとして、対象外扱いではない独立した backlog 項目として管理されている。
  本 ADR が対象外とするのは個人アカウント版のみである。

### Viber

- 2024-02-05 以降、Viber の bot/business メッセージングは**商用契約のみ**となり、
  最低でも月額約 **€100** かかる。
- 従来の調査結果への訂正:中核事実(有料の商用ゲート)は正しいが、以前引用した
  「約 15 分のリトライ」という運用上の詳細は不正確であり、本 ADR ではこれに依拠
  していない。
- 結論:固定の月額下限があるため、具体的な需要が生まれるまでは、個人 / 一人会社を
  ターゲットとするユーザーにとっては採算が合わない。
- Source: https://developers.viber.com/docs/api/rest-bot-api/

## Consequences

- この 3 つは「評価済み、見送り」としてマークされ、今後の計画では再度トリアージ
  しなくてよい。
- Signal/Viber へのリーチが必要なユーザーは、ファーストパーティコネクタではなく、
  Matrix ブリッジ(Matrix は対象外ではない別の候補)または email 経由でルーティング
  すべきである。
- ブロッキング条件のいずれかが変化した場合(Signal が公式 bot API を公開した、
  Viber に無料/低価格ティアが登場した等)、本 ADR を上書きする新しい ADR で
  再検討を行う。
