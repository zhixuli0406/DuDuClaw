## 四、真機驗證 checklist（需真 x86-64 機器，只能你做）

QEMU 無法測 genericx86-64（真機 target，runqemu 不支援）。qemu 版兩式已代驗同一套修復鏈。
真機至少驗一次：

- [ ] 下載 `duduclaw-os-installer-duduclaw-genericx86-64-v0.1.0.iso` + `.minisig` + `.sha256`
- [ ] 驗簽：`minisign -V -P RWQyI00ugZ/+WVisQ2ZnKeTqFs8Ze8h2X11FO9Z8le0YubFMXYTwQD7n -m <iso>`
- [ ] 驗 sha：`shasum -a 256 -c <iso>.sha256`
- [ ] 燒 USB：`zstd -d` 不需要（iso 直接燒）；`dd if=<iso> of=/dev/<usb> bs=4M conv=fsync` 或 balenaEtcher
- [ ] 目標機 UEFI 開機、Secure Boot 先設 setup mode 或關（首開機自動 enroll DuDuClaw 金鑰）
- [ ] 從 USB 開機 → 圖形安裝器起來 → 選目標 SSD → 安裝（dd A/B image 到磁碟）
- [ ] 重開 → 落在 A/B UKI+systemd-boot 系統 → LAN 上瀏覽器連 dashboard
- [ ] 驗 A/B 更新 + rollback（可選，`device.update_apply`）
- [ ] 回報結果；若開機/安裝有問題貼 serial log，依證據除錯

（整碟 `.wic` 路線：`zstd -d <wic.zst>` 後 `bmaptool copy` 或 `dd` 到目標磁碟，跳過安裝器。）
