## 7. 本日根因戰果（值得固化）

1. **gitleaks `detect` vs `dir`**：v8.19+ `detect`＝git-history 模式，非 git 目錄「0 commits scanned, ~0 bytes」**還 exit 0**——每日定掃 /data/duduclaw 永遠假乾淨，exit-code 防線都穿過。修法＝依 `.git` 選模式。
2. **AWS 範例鍵 allowlist**：`AKIAIOSFODNN7EXAMPLE` 是 gitleaks 預設規則刻意放行的官方文件範例——測資改 format-valid 假 GitHub PAT（`ghp_`+36 alnum，實測抓到 `github-pat` finding）。
3. **無 report 檔＝乾淨的 fail-open**：非零 exit＋無檔已改記 parse_error（安全掃描器 fail-closed 慣例 4）。
4. **GO_INSTALL `/...` 雜訊**：go.bbclass 預設會編所有 `package main`——多裝 9.9MB `/usr/bin/config`。
5. **免開 VM 活測 target binary 技巧**：deploy-rpms＋`openembedded-core/scripts/rpm2cpio.sh` 解包→`sysroots-components/aarch64/qemu-native/usr/bin/qemu-x86_64 -L <sysroots-components/x86-64-v3/glibc> -E LD_LIBRARY_PATH=<go-runtime dynlink 目錄>` 直接跑。Yocto Go binary 是動態連結（需 libstd.so）。
6. （R1 戰果，已固化在 recipe 註解）meta-networking nftables recipe 不裝 systemd unit；wrynose `S = "${WORKDIR}/git"` 硬錯誤；recipetool go 三連敗→vendor tarball 路線；`inherit go-mod`（不是 `go`）才會把 cwd 放進 module 目錄。
