# 2026-10-01 — Discovery 六 runtime 同等能力、Antigravity 憑證修正、Gemini CLI 棄用、兩個沙箱重建與加固、契約鎖、computer-use image 重做、公開文件全面校正（全部未 commit）

## 今日做了什麼

1. **Discovery 外部活驗與修復（上午）**：Provider 與正式瀏覽器活驗抓到 L1–L13，同日修復重驗。細節在 `commercial/docs/REPORT-release-live-validation-2026-10-01.md`。
2. **Discovery 六個 runtime 同等能力**：Claude／Codex／Gemini／Antigravity／Grok／OpenAI 相容在同一份契約下跑 attempt。步數上限與「只能用檔案與 shell 工具」由主機端的串流守衛（`discovery/attempt_guard.rs`）讀各 CLI 的事件流強制，CLI 自己的旗標只當第二道防線。Codex、Grok 各完成一次真實生成。
3. **Antigravity（`agy`）憑證與 MCP 修正**：實測 agy 1.2.14 後確認 `ANTIGRAVITY_API_KEY` 不存在、`agy login` 不存在、settings.json 裡的 `mcpServers` 不會被讀。改為 `config.toml [antigravity] auth`、Gemini API key、`<work_root>/.agents/mcp_config.json`。
4. **Gemini CLI runtime 棄用（R1）**：v1.67.0 標記、v1.69.0 移除，由 Antigravity 接手。讀取時每個行程警告一次、經儀表板寫入時記稽核事件 `runtime_provider_deprecated`、儀表板不再提供新選取、`doctor` 列出仍在用的員工。Gemini API provider 不在範圍。
5. **任務沙箱重建**：`agent.toml [container] sandbox_enabled` 從上線起沒跑通過（image 沒人建、金鑰用 Claude Code 不讀的變數傳、預設不連網、沒有可寫 HOME、Docker 不在時靜默改成不隔離）。改為重用 Discovery 的容器機制，預設 fail closed。
6. **腳本沙箱（PTC `execute_program`、`secaudit` PoC）**：同一個沒人建置的 image 也是它的預設，所以 PTC 實際上一直在主機上跑。改為共用 `[container.sandbox] image`、不自動下載、非 root、丟棄 capability。
7. **公開文件盤點與修正**：逐頁對照程式碼修正，三語翻譯補到逐節一致，索引補齊。

## 活測抓到的問題

- **預設 image 標籤錯誤**：程式寫 `duduclaw:<版本>`，發布流程推的是 `v<版本>`（前者 404）。`distribution/umbrel` 的 compose 檔也有同樣的錯。
- **L14**：沙箱拒絕執行時，委派方收到的是「未知錯誤」，原因與 `docker pull` 提示被 dispatcher 蓋掉。改為型別化錯誤後直達回覆，原始 CLI／Docker 輸出只留在主機 log。
- **CLI 測試沒跑到的兩個錯**：`doctor` 在沒有 `agents/` 的 home 上回 Warn；一個真 Docker 測試的 Python 腳本縮排錯誤。
- **文件稽核順帶發現的程式事實**（當時只修文件；前三件已於使用者拍板後修正，見「拍板後續」）：Ed25519 challenge-response 認證沒有任何正式路徑會啟用；`must_always` 實際上沒有任何地方強制；`duduclaw-eval-dom` 不存在於 computer-use image，所以容器截圖一律全黑；`cleanup_expired`（瀏覽器稽核 7 天保留）沒有呼叫端。

## 行為變更（升級者會遇到）

- `sandbox_enabled = true` 的員工，沙箱不可用時任務失敗，不再靜默改成不隔離；`network_access = false` 會被拒絕。
- PTC `execute_program` 預設拒絕執行，直到 `docker pull` 沙箱 image，或設 `[container.sandbox] script_when_unavailable = "run_unsandboxed"`。
- Discovery 的評分與策略容器也改為 `--pull never`。
- 儀表板不再提供 Gemini CLI 作為新選項；精靈預設改為 Antigravity。
- 開了沙箱的員工不再組成 Team，新信件不會自動喚醒他們。
- AI 員工不能再改寫自己的 `CONTRACT.toml`；live fork 採用不會把 agent 結構檔帶回員工目錄。
- computer-use image 必須手動重建（`docker build -f container/Dockerfile.computer-use -t duduclaw-computer-use:latest .`）。
